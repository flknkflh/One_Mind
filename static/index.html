Memeriksa kunci lokal...

Backup file server tidak sama dengan backup kunci user.

Private key DIPP akun ini disimpan di localStorage browser dalam bentuk terenkripsi memakai password akun. Jika data browser, profil browser, atau perangkat hilang, file lama tidak bisa didekripsi dari server saja.

Tata cara aman sebelum pindah perangkat

  1. Pastikan masih bisa login dan mengunduh file dari browser lama.
  2. Jangan hapus cache, localStorage, profil browser, atau instal ulang sistem sebelum semua file penting berhasil dibuka di perangkat baru.
  3. Simpan password akun di password manager atau catatan offline yang aman.
  4. Untuk migrasi server, backup volume one_mind_data. Untuk pindah perangkat, export encrypted private key lalu simpan file backup dan password backup secara terpisah.
