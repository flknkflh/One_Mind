Identitas Digital ONE_MIND akan dibuat dan diunduh ke komputer Anda.

Server tidak pernah menyimpan Private Key DIPP maupun RSA Login Key. Setelah registrasi, browser akan mengunduh dua file:

• ONE_MIND_DIPP (.dipp)
Digunakan untuk membuka, mengenkripsi, mendekripsi, dan membagikan file di dalam aplikasi.

• ONE_MIND_RSA (.key)
Wajib digunakan pada setiap login untuk menandatangani challenge RSA. Pada login pertama, challenge yang berhasil sekaligus mengaktifkan certificate akun di server.

Simpan kedua file tersebut dengan aman. Kehilangan salah satunya dapat membuat akun atau data tidak dapat digunakan.

ONE_MIND Identity

Private Key DIPP dan RSA Login Key tidak pernah disimpan di server maupun browser.

Kedua private key hanya berada pada file identitas milik pengguna dan RAM browser selama sesi aktif.

  • ONE_MIND_DIPP (.dipp) untuk operasi kriptografi file.
  • ONE_MIND_RSA (.key) untuk challenge pada setiap login.
  • Certificate disimpan server sebagai status aktivasi akun setelah login pertama berhasil.

Jangan membagikan file DIPP atau RSA Login Key kepada siapa pun.

Praktik yang Direkomendasikan

  1. Simpan file ONE_MIND_DIPP dan ONE_MIND_RSA.
  2. Backup kedua file ke media offline yang aman.
  3. Jangan pernah membagikan kedua file tersebut.
  4. Jika berpindah komputer, gunakan file DIPP dan RSA Login Key yang sama saat login.
